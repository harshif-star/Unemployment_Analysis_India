# 📊 Unemployment Analysis with Python

## 📌 Project Overview

This project performs Exploratory Data Analysis (EDA) on unemployment data from India to identify regional and temporal patterns in unemployment rates and examine the impact of the COVID-19 pandemic on India's labour market.

The project uses Python-based data analysis and visualization techniques to explore unemployment rates, employment levels, and labour participation across different regions and time periods.

---

## 🎯 Objective

The main objective is to analyze unemployment trends in India and identify:

* Regional differences in unemployment rates
* Changes in unemployment over time
* Regions with higher average unemployment
* Relationships between unemployment, employment, and labour participation
* Differences between pre-COVID and post-COVID labour-market conditions

---

## 📊 Dataset

The project uses the **Unemployment in India** dataset containing information related to India's labour market.

The dataset includes:

* Region
* Date
* Frequency
* Estimated Unemployment Rate (%)
* Estimated Employed
* Estimated Labour Participation Rate (%)

---

## 🔍 Exploratory Data Analysis

The analysis includes:

* Dataset shape and structure
* Data type inspection
* Missing-value analysis
* Descriptive statistics
* Region-wise average unemployment rates
* Time-series unemployment trends
* Top 10 regions with the highest average unemployment rates
* Correlation analysis
* Pre-COVID vs post-COVID comparison

---

## 📈 Visualizations

The project includes several visualizations:

### 1. Region-wise Average Unemployment

A comparison of average unemployment rates across regions.

### 2. Time-Series Analysis

A line chart showing how unemployment rates changed over time.

### 3. Top 10 Regions

A bar chart identifying regions with the highest average unemployment rates.

### 4. Correlation Heatmap

A heatmap examining relationships between:

* Unemployment Rate
* Estimated Employment
* Labour Participation Rate

### 5. COVID-19 Impact

A comparison of labour-market indicators between the pre-COVID and post-COVID periods.

---

## 🦠 COVID-19 Analysis

The dataset was divided into two periods:

* **Pre-COVID:** Before March 2020
* **Post-COVID:** March 2020 onwards

Average unemployment and labour-market indicators were calculated for both periods to understand changes associated with the pandemic.
